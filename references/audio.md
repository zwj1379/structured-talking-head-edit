# 音频、变速与背景音乐

## 整体变速

整体变速只在用户明确要求或试听确认后执行。不要默认把所有素材加速 1.1 倍。

优先使用编辑器中能真实缩短片段时长、同时保持音高且可回退的能力。若当前时间线的速度参数语义不可靠，可生成派生素材：

```bash
ffmpeg -i input.mp4 \
  -filter:v "setpts=PTS/<rate>" \
  -filter:a "atempo=<rate>" \
  -c:v libx264 -preset slow -crf 18 -c:a aac -b:a 192k \
  output-<rate>x.mp4
```

保留原素材，并记录新旧时长比例。若语速、情绪或咬字受损，降低倍率或取消变速。

## 判断是否需要降噪

`ffprobe` 只用于确认流、编码和时长，不能代替听感分析。需要测量时使用 `ffmpeg` 音频滤镜，并结合试听：

```bash
ffmpeg -i input.mp4 -af "silencedetect=noise=-40dB:d=0.3,astats=metadata=1:reset=1" -f null -
```

选择至少三类片段试听：正常讲话、说话间隙、最明显噪声处。空调、风噪、持续嘶声、明显混响或电流声影响理解时，才考虑处理。

不要把单一 dBFS 阈值当作通用结论：录音增益、说话距离和后期归一化都会改变数值。没有接近 -50dB 的真静音，也不能单独证明必须降噪。

## 降噪执行与验收

- 先在代表片段上做 A/B，再应用全片。
- 从克制强度开始，逐步增加；不要固定使用最大强度。
- 重点检查辅音、齿音、尾音、呼吸和房间感是否被破坏。
- 处理后应提高可懂度，而不是仅让波形更安静。
- 不确定时保留原音，并把问题交给用户试听判断。

## 背景音乐

0dB 表示保持素材原始增益，不代表它与人声混合后一定合适。除非用户明确要求保留原始增益，否则以人声清晰为优先，按试听调整 BGM 电平并避免削波。

- BGM 裁到主轨长度，结尾按内容做自然淡出。
- 检查开头、最响段、安静段和结尾。
- 用户明确指定 0dB 时照做，但仍报告可能遮蔽人声或削波的风险。
