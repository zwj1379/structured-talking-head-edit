# B-roll 与真人提示窗

## 通用 B-roll

优先级：用户指定素材 → 项目已有素材 → 用户允许搜索的公共素材 → 用户明确允许生成的素材。

- B-roll 用于解释内容、展示对象或场景、提供证据、遮盖必要跳切或缓解画面单调。
- 动态视频和静态图片都可以使用，以信息表达和素材质量为准。
- 有音轨且不需要原声的素材必须静音；无音轨素材不要调用音量或静音接口。
- 核心观点和情绪表达优先保留真人。
- 不遮挡人脸、嘴部、手势、字幕、产品、Logo 和关键信息。
- 检查每段进入、中间和退出画面，确认构图、裁切和时长真实有效。

真人窗不是每段 B-roll 的默认要求。只有用户提出、已选风格方案要求，或启用下述 Riso preset 时才添加。

## `riso-presenter-248` preset

此 preset 仅用于 1080×1920、30fps 的 Riso B-roll，并与 `eian-riso-broll` 联用。其他画幅不得直接套用固定坐标。

1. 先锁定最终 V1 主轨，再制作 V2/V3；任何上游删改都要重新计算下游时间点。
2. V2 放净版 1080×1920 Riso B-roll；V3 放同步的 248×248 真人窗。
3. 真人内容 240×240；2px A 墨框；B 墨向右、向下各错位 4px；组合尺寸 248×248。
4. 原尺寸放置 `left=792`、`top=40`；可见范围 `x=792–1040 / y=40–288`。
5. 正文、数字和结构线距离可见窗口至少 16px。
6. 真人窗必须来自最终 V1 对应时间段，并复刻相同剪切、速度、入点和时长。
7. V2、V3 都使用无音轨素材；全片人声只来自 V1。
8. 进入、中间、退出三帧必须检查切头、黑帧、冻结、边框残缺、越界和遮挡。

推荐沿用 `eian-riso-broll/scripts/compose_presenter_window.mjs` 的人物侧处理顺序生成独立 V3 素材：正方形裁切 → 240×240 缩放 → 轻微色彩校正 → A/B 墨边框 → 输出 248×248、30fps、无音轨。

不要给该预裁素材再加 Rectangle Mask、缩放或二次裁切。需要圆角时应在生成素材时完成，且当前确认规格默认直角。旧的 450×800 静态图片窗和裸视频蒙版方案均不属于本 preset。

若固定裁切无法完整保留头发、眼镜、下巴和部分肩部，可使用少量关键帧平滑跟随。仍无法稳定构图时，放弃该段 B-roll，保留 A-roll 主画面。

开头是否先展示一段纯 A-roll 由内容和用户选择决定；如果当前项目明确采用“前 2 秒 A-roll”规则，第一条覆盖层不得早于 `00:02.000`，否则不要擅自添加该限制。
